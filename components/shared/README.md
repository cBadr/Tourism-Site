# المكوّنات المشتركة
- **HelpTip** (اعتبار ٧): `<HelpTip>نص إرشادي يشرح الخيار</HelpTip>` — أيقونة «؟» صغيرة بجوار أي حقل أو خيار في اللوحات، تعرض التلميح بالتحويم أو التركيز، وتعمل في مكوّنات الخادم والعميل بلا مكتبات إضافية.
- **اتفاقية إعادة التوجيه بعد العمليات** (اعتبار ٨): كل Server Action ينتهي وجوباً بـ `redirect()` إلى صفحة قائمة الكيان أو تفاصيله — لا يبقى المستخدم على شاشة النموذج بعد الحفظ أبداً.
