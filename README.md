# منصة النقل السياحي — Tours-01

منصة حجز نقل سياحي في مصر: العميل يحدد نقطتين وعدد الركاب فيحصل على سعر فوري لكل
فئة سيارة مناسبة، ويحجز ويدفع؛ والتنفيذ يمر إلى **متعهدين** يُبَث إليهم الطلب
تلقائياً فيقبله أولهم. المنصة **بيضاء العلامة (white-label)**: كل قيمة تخص
العلامة تعيش في قاعدة البيانات، فتُطلق النسخة الواحدة باسم وهوية ودومين مختلفين
بلا تعديل سطر كود.

> **ابدأ من [`handover/INDEX.md`](handover/INDEX.md).**
> هي حزمة التسليم الكاملة: نظرة عامة، معمارية، منطق الأعمال، خريطة الملفات،
> إعداد البيئة، الاتفاقيات، المهام المفتوحة، والدروس المستفادة.
> والمرجع الأعلى للمنتج هو [`docs/VISION.md`](docs/VISION.md)، وسجل التقدم الحي
> [`docs/ROADMAP.md`](docs/ROADMAP.md).

## ما الذي يعمل الآن

| المجال | الحالة |
|---|---|
| موقع عام عربي RTL (١٤ صفحة: ٦ خدمات + ٦ مسارات سيو + ثابتة) بمحتوى من نظام أقسام يُدار من اللوحة | ✅ |
| محرك مسافات وتسعير في Postgres (تعريفة كيلومتر · أسعار متعهدين + هامش · عمولة ذروة) | ✅ |
| حجز كضيف + دفع محلي (محافظ وانستا باي) برفع إيصال وتحقق يدوي | ✅ |
| بورتال المتعهدين: أسطول وقوائم أسعار جغرافية باعتماد إداري | ✅ |
| بث الطلب على موجات + قبول ذرّي «أول قابل يفوز» + تصعيد يدوي | ✅ |
| مالية كاملة: دفتر نقدية واحد · خزينة · مصروفات · مقاصة متعهدين · تدفق نقدي | ✅ |
| لغات: عربي أساس بلا بادئة + إنجليزي على `/en` بترجمة آلية تُراجَع وتُنشر | ✅ |
| بوابات دفع: طبقة موحّدة + ٦ محوّلات + مزوّد اختباري يعمل بلا حسابات | ✅ |
| الربط الخارجي والإحصائيات · وكيل ذكاء اصطناعي · ولاء وخصومات · Page Builder · مصنع النسخ | ⏳ المراحل ١٠–١٤ |

**غير منشور بعد** — بقرار صريح: الاكتمال والاختبار أولاً، ثم الدومين والنشر.

## الحزمة التقنية

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind v4 · shadcn/ui ·
Supabase (Postgres 17 + Auth + Storage) · pnpm.

**مبدأ حاكم:** كل حساب مالي أو تسعيري يقع داخل دوال وviews في Postgres.
TypeScript يعرض الأرقام ولا يحسبها.

## التشغيل السريع

```bash
pnpm install
cp .env.example .env.local     # ثم املأ القيم — التفاصيل في handover/ENVIRONMENT.md
pnpm db:migrate                # تطبيق الهجرات (٢١ هجرة)
pnpm db:test                   # ٧ مجموعات اختبار — النجاح = ALL PASSED في كل واحدة
pnpm dev                       # http://localhost:3000
```

| الأمر | ماذا يفعل |
|---|---|
| `pnpm db:migrate` | يطبّق الهجرات الجديدة ويتتبعها في `schema_migrations` |
| `pnpm db:test [filter]` | يشغّل `supabase/tests/*.sql` على القاعدة الحية |
| `node scripts/invite-admin.mjs <email>` | دعوة مشرف (يحدد كلمة مروره بنفسه) |
| `node scripts/invite-subcontractor.mjs <email> "<شركة>" <هاتف>` | دعوة متعهد |
| `node scripts/demo-subcontractor.mjs [--clean]` | سيناريو تحقق حي لتسعير المتعهدين |
